# 04 · 部署与使用

## 1. 设备与软件要求

| 项 | 要求 |
| --- | --- |
| PDA | Android 8.0+（minSdk 26），推荐东集 CRUISE2 等带广播扫码的工业手持 |
| 电脑 | Windows 10/11，Python 3.10+，与 PDA 在同一局域网 |
| 网络 | 普通 WiFi 路由器即可；关闭「AP 隔离 / 客户端隔离」 |
| 磁盘 | 源表 + 数据库约 100 MB 足够 |

## 2. 电脑端部署

```powershell
# 1) 项目放到电脑，例如 E:\peijian
# 2) 把最新的 配件记录.xlsx 放到 E:\peijian\ 或 E:\peijian\pc-server\
# 3) 双击 pc-server\启动同步服务.bat
```

首次启动会创建虚拟环境并安装依赖（约 1-2 分钟），完成后浏览器自动打开
`http://127.0.0.1:8000`。

Windows 防火墙弹窗务必勾选 **专用网络** 并允许；若已点过「取消」，到
「Windows Defender 防火墙 → 允许应用通过防火墙」里把 Python 勾上，或放行 8000 端口。

### 2.1 验证

- 首页能看到「总箱数 / 在库箱 / 数据版本 rev / 上次导入结果」；
- 行情正常时应为：总箱数 ≈ 20929、明细 22554 行、导入约 1.1 秒；
- 点「下载库存清单（在库）」，Excel 打开后第一个 sheet 有 17 列、第二个 sheet 是物料汇总。

### 2.2 换电脑 / 换路径

- 源表放在别处：在 `pc-server/data/config.json` 写
  `{"xlsx": "D:/共享/配件记录.xlsx"}`；
- 或设置环境变量 `PEIJIAN_XLSX`；
- 迁移时连同 `pc-server/data/`（令牌 + 数据库）一起拷走，PDA 不用重新配对。

## 3. PDA 安装

### 3.1 编译

```powershell
cd E:\peijian
.\gradlew.bat assembleDebug
# 产物：app\build\outputs\apk\debug\app-debug.apk
```

要求 JDK 17（`gradle.properties` 已固定 `org.gradle.java.home`），Android SDK 已装。

### 3.2 安装

用数据线 / U 盘 / 微信把 APK 拷到 PDA，点击安装（需允许「未知来源应用」）。
首次进入会申请存储权限，用于把导出文件写到 `/sdcard/Peijian/导出/`。

### 3.3 扫码枪设置

两条通道，任选其一即可：

1. **广播模式（推荐）**
   东集「扫描设置 → 输出方式 → 广播」，动作 `com.android.server.scannerservice.broadcast`，
   数据键 `scannerdata`。App 已内置该动作，也兼容 `android.intent.action.SCANRESULT`、
   `urovo.rcv.message` 等常见动作。
2. **键盘模拟（HID）**
   输出方式选「键盘 / 模拟按键」。各扫码页的输入框会自动聚焦，扫码后自动提交；
   若未自动回车，把扫描枪设置为"追加回车/CR"。

> 两种模式同时开启时，App 做了 700ms 去重，不会重复记账。

## 4. 首次配对

1. 电脑端首页 →「PDA 配对」，显示二维码；
2. PDA → 底部「数据同步」（首页快捷入口）→「扫码配对」；
3. 用扫码枪扫电脑屏幕上的二维码 → 自动填入地址与令牌；
4. 点「保存并测试」，提示 `连接成功：peijian-sync 0.1.0 @ …` 即可；
5. 点「拉取新增」，首次会拉取全部约 2 万箱（约 1-2 分钟，取决于 WiFi）。

无扫码枪时手输：地址 `192.168.1.5:8000`，令牌见电脑端首页 `data/token.txt`。

## 5. 日常作业

### 5.1 每天开工

1. 电脑更新 `配件记录.xlsx`（保存后无需操作，服务会自动重新导入）；
2. PDA「数据同步 → 拉取新增」；
3. 首页确认「在库箱数」与预期一致。

### 5.2 打包贴码

1. 电脑浏览器打开 `http://127.0.0.1:8000/labels`；
2. 选生产单号、箱号区间（如 1~20），选 Code128 或二维码，点「生成」；
3. 浏览器打印（标签打印机 40×30mm，或 A4 不干胶）；
4. 贴到对应箱外侧。

### 5.3 发货

1. 「扫码出库」→ 填发货单号（默认 FH+时间戳）、客户、收货人、备注 → 建立；
2. 逐箱扫箱码：
   - 成功：震动 1 下，显示箱号、配件明细与件数；
   - 重复扫本单：提示"这一箱已经扫过"；
   - 已发出：提示"已于 … 发出"；
   - 箱码重复/不存在：震动 2 下并给出原因。
3. 扫完点「完成发货」→「数据同步 → 立即上传」；
4. 电脑端「下载出库明细」核对。

### 5.4 盘点

1. 「库存盘点」→ 填批次号（默认 PD+时间戳）→ 开始；
2. 逐箱扫码（只核对，不改状态）；
3. 结束盘点 →「导出报表 → 盘点差异」；
4. 导出的 Excel 含：盘点汇总、盘点差异（按配件编码）、盘亏箱、盘盈/异常、未知箱码、扫描明细。

### 5.5 报表

「导出报表」页：

- **库存清单 + 物料汇总**：文件写到 `/sdcard/Peijian/导出/`，同时弹出分享面板（微信/企业微信/U 盘）；
- **出库明细**：按发货单导出；
- **盘点差异**：按批次导出。

电脑端也可以直接下载，路径见 `/` 首页。

## 6. 数据备份

| 数据 | 位置 | 建议 |
| --- | --- | --- |
| 源表 | `配件记录.xlsx` | 每天备份，是唯一权威台账 |
| 电脑端库 | `pc-server/data/sync.db` | 每周复制一份 |
| 配对令牌 | `pc-server/data/token.txt` | 丢失只需重新配对 |
| PDA 数据 | 应用内部 Room 库 | 见下方「PDA 数据库备份」——未上传单据只在本机，务必备份 |

### 6.1 PDA 数据库备份（重要）

未上传的发货单 / 盘点只存在 PDA 本机，设备丢失或损坏就会丢失。「数据同步」页新增了备份入口：

- **立即备份**：把全库 + 同步进度（`lastRev` 等）打包成一个 zip，写到 `/sdcard/Peijian/备份/`（不可写时退到 App 专属目录），并弹出分享面板，可发到电脑 / 微信保存。建议**每天收工前备份一次**。
- **从备份恢复**：选之前导出的 zip，应用校验格式、版本和校验和通过后弹出确认框（显示箱数、未上传单数、创建时间）；确认后先自动为当前库另存一份备份，再覆盖数据库与同步进度，最后自动重启。

注意事项：

- 备份前会执行 `wal_checkpoint(TRUNCATE)`，确保 WAL 中未归并的数据（正是最近的未上传单据）写入主库后再复制，避免只拷 `.db` 丢数据。
- **同步进度和数据库一起备份/恢复**：只恢复库不恢复 `lastRev` 会导致增量同步漏数据。
- 恢复会覆盖当前全部数据，且高版本数据库备份不能在低版本应用上恢复；恢复前自动备份可用于回退。
- zip 内含 SHA-256 校验，损坏或被篡改的备份会被拒绝。

## 7. 常见问题

**PDA 提示「还没配置电脑端地址」** → 同步页填写或扫码配对后点保存。

**PDA 浏览器打不开电脑地址** → 检查同一网段、防火墙、路由器 AP 隔离；用 `ipconfig` 确认 IP 未变（建议路由器给电脑固定 IP）。

**拉取后箱数少** → 首页看 `lastReport` 的 `boxes`；若源表本身少了，检查 Excel 是否另存成了 `.xls`（只支持 `.xlsx`）。

**扫码无反应** → 先用纸张打印箱码测试；确认扫描枪输出方式为广播或 HID；也可在扫码页手动输入箱码点「录入」。

**导出提示写入 App 专属目录** → ROM 不允许写 `/sdcard` 根目录，文件仍在手机里，按提示路径用文件管理器取。

**同一箱扫出多个结果** → 源表箱号重复，按「设置 → 重复箱号处理 → 合并数量」重新导入，或源头修正箱号。

**换手机** → 新机装 APK、重新配对、拉取全量即可；未上传的发货单请先在旧机上传。
