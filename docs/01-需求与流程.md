# 01 · 需求与业务流程

## 1. 背景

售后配件仓目前的台账是 Excel 文件 `配件记录.xlsx` 的 **打包记录** 工作表（17 列，约 2.2 万行、2 万个箱、1700 个配件编码）。
打包时由电脑排版并打印箱码，箱子入库；发货时按箱整箱出库；月末需要盘点并给出差异；财务需要按配件编码汇总的数量。

原来的问题：

- 出库靠纸单勾箱，容易漏扫、重扫，事后无法追溯某一箱是什么时候发走的；
- 盘点靠翻 Excel 手工对，2 万个箱根本对不完；
- 库存清单和物料汇总每次都要人工透视，容易出错；
- Excel 与现场不同步，PDA 上没有可信的"这一箱里有什么"。

## 2. 目标

| 编号 | 需求 | 落地方式 |
| --- | --- | --- |
| R1 | 把 Excel 的新增/修改同步到 PDA | 电脑端服务自动解析 + PDA 增量拉取（`rev`）；也支持 PDA 直接选 xlsx 导入 |
| R2 | 整箱扫码出库并带发货单信息 | 先建发货单（单号/客户/收货人/备注），再逐箱扫码，箱内配件按快照记账 |
| R3 | 扫箱盘点 | 建盘点批次，逐箱扫码；系统应存但没扫到的 = 盘亏，扫到已发出/不存在的 = 异常 |
| R4 | 导出库存清单 + 物料汇总 | 库存清单保持打包记录 17 列；物料汇总按配件编码合计数量、箱数 |
| R5 | 生成箱码并扫描识别 | 箱码 = 客户编码 + 生产单号 + 箱号；带/不带分隔符均可识别 |
| R6 | 操作留痕 | 发货单、盘点批次、每条扫描记录都带操作员与时间 |

## 3. 角色

- **打包/仓管**：打包后在电脑上打印箱码贴箱，必要时补录。
- **发货员（PDA）**：建发货单 → 扫箱 → 完成 → 上传。
- **盘点员（PDA）**：建盘点批次 → 扫箱 → 结束 → 导出差异。
- **财务/主管**：电脑或 PDA 导出库存清单、物料汇总、出库明细、盘点差异。

## 4. 主流程

### 4.1 数据准备（每天开工前）

```
Excel 更新  →  电脑端服务检测到文件变化  →  自动解析入库（rev+1）
                    ↓
             PDA「数据同步」→ 拉取新增（只取 rev > 本地记录的箱）
```

没有网络时：PDA「数据同步 → 导入 Excel」直接选手机里的 `配件记录.xlsx`。

### 4.2 打包与贴码

1. 电脑打开 `/labels`，选生产单号、箱号区间，选 Code128 或二维码；
2. 打印后贴在对应箱子外侧（标签内容与系统里的箱码完全一致）；
3. 若先贴码后录 Excel：补录后 PDA 拉一次即可扫到。

### 4.3 扫码出库

```
新建发货单（单号自动 FH+时间戳，可改）
   ↓
扫箱码 → 校验：箱存在？本单是否已扫？是否已发出？
   ↓ 通过
写 shipment_box + shipment_item（箱内配件快照）+ 箱状态改 SHIPPED
   ↓
完成发货 → 状态 FINISHED → 「上传」把整单发给电脑
```

- 扫错可单箱「撤回」（箱回在库、明细删除）；
- 未完成前可「取消发货单」，已扫箱全部回在库；
- 已完成的发货单不能取消，历史出库数据保持不变（即使以后源表改了）。

### 4.4 扫箱盘点

```
新建盘点批次
   ↓
逐箱扫码 → 在库的箱记为"匹配"，已发出/系统无此箱记为"异常"，重复扫提示
   ↓
结束盘点 → 计算差异：
   实盘 = 本批次扫到的「在库」箱的配件数量合计
   账面 = 当前系统在库的全部配件数量合计
   差异 = 实盘 − 账面（按配件编码）
   盘亏箱 = 系统在库但本批次没扫到的箱
```

盘点**不修改**箱的在库状态，只记录这一次的核对结果。

### 4.5 报表

| 报表 | 内容 | 出口 |
| --- | --- | --- |
| 库存清单 | 在库箱，17 列（与打包记录一致） | PDA 导出 / 电脑下载 |
| 物料汇总 | 配件编码、名称、英文描述、整机型号、数量合计、箱数、明细行数 + 合计行 | 同上（第二个 sheet） |
| 出库明细 | 发货单号、出库时间、客户、收货人、单号、箱号、箱码、配件、数量、操作员 | PDA 导出 / 电脑下载 |
| 发货单汇总 | 单号、客户、箱数、配件数量、操作员、完成时间 | 电脑下载 |
| 盘点差异 | 汇总、按配件差异、盘亏箱、盘盈/异常、未知箱码、扫描明细 | PDA 导出 |

## 5. 边界与已知限制

- 箱码唯一性依赖源表「客户编码 + 单号 + 箱号」唯一。源表存在约 1000 行重复箱号，默认按 **MERGE** 合并数量；扫到多义箱码时提示"箱码重复"，不猜。
- 源表 2 行的箱号为空，导入时按箱号 `0` 占位，建议源头补全。
- 箱码标签由电脑端生成；PDA 只负责识别，不打印。
- 盘点只做整箱核对，不做拆箱/散件盘点。
- 网络只在同步/上传时需要，扫码出库与盘点全程离线可用。
